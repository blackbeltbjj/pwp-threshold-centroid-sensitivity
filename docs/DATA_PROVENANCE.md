# Data Provenance

Primary SST dataset: NOAA daily OISST.

Frozen analysis:
1981-09-01 through 2026-07-29

Grid:
0.25° × 0.25°

Raw annual NetCDF files are not redistributed in this Git repository.

The release must preserve:
- exact product identity;
- official acquisition source;
- temporal selection;
- grid definition;
- input manifests/checksums where feasible.
